# SatQuery AI

**Interactive Vision-Language Assistant for Multimodal Remote Sensing Image Analysis**

Smart India Hackathon 2026 | Problem Statement: SIH26167 (ISRO)

### Overview
SatQuery AI allows users to ask natural language questions about multimodal satellite imagery and receive accurate, source-cited answers with visual grounding (bounding boxes / heatmaps).

### Tech Stack
- Python, PyTorch, Hugging Face Transformers
- Vision-Language Models (LLaVA / RemoteCLIP style)
- Streamlit / FastAPI
- Rasterio, GDAL, OpenCV
