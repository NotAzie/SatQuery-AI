# Third-Party Model Runtime

SatQuery AI includes an optional adapter for the externally installed GeoChat
runtime and checkpoint. GeoChat source is not copied into this repository.

When using that adapter, retain the upstream project license and attribution from
the GeoChat repository and model distribution. The upstream project is available
at <https://github.com/mbzuai-oryx/GeoChat> and is distributed under the Apache
License, Version 2.0. The GeoChat model checkpoint may have additional terms;
review its model card before redistribution or commercial use.

The adapter code under `satquery_ai/vision/` is SatQuery AI code owned by Az.
