# Research and product directions

This file records directions, not implemented capabilities. The current
implementation boundary is maintained in [implementation status](../IMPLEMENTATION_STATUS.md)
and the [roadmap](../foundation/ROADMAP.md).

Potential research directions, each requiring an explicit design and evidence
plan before implementation:

- Broader modality and dataset coverage with truthful capability/latency and
  access metadata.
- Validated, source-aware raster/temporal processing and uncertainty models.
- General Earth Object extraction beyond explicit provider records and
  caller-mapped categorical components, backed by suitable reference data.
- Spatial/temporal joins with declared support semantics, CRS transformations,
  resolution policy, and reproducibility.
- Independently validated scientific methods and representative benchmark
  datasets with compatible redistribution licenses.
- Search and indexing suitable for larger multi-organization Earth Memory
  deployments, with authorization and data governance requirements specified.
- Distributed execution, external notifications, public SDK/versioning, and
  deployment profiles after operational requirements are provided.
- Human-reviewed collaboration or model-assisted planning, isolated from
  canonical evidence and bounded by reproducibility and governance.

No item above should be described as current functionality until its actual
runtime path and limitations are documented.
