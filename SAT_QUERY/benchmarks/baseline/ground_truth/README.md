# Ground Truth Status

No ground-truth annotations are present for the current seven checked-in imagery fixtures.

Therefore the Phase 0 runner reports qualitative predictions and runtime only. It must not report:

- caption factual accuracy;
- VQA accuracy;
- scene accuracy or macro F1;
- grounding IoU or localization recall;
- counting MAE;
- change precision/recall/F1;
- modality accuracy.

A future labeled benchmark must record source, license, sensor, modality, acquisition date, resolution/GSD, CRS, task labels, and annotation provenance before these metrics are calculated.
